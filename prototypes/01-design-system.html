01设计理念

整个小程序 = 一本被涂鸦过的作业本。用户是闯关的学生，AI 是出题的老师：答题 = 写作业， 答对 = 老师打勾发小红花，答错 = 红笔圈出来订正，通关 = 满分卷子贴上光荣墙。 v1.1 在保持意境的前提下做「减法」：一屏只用力一次 —— 小智表情、GO 按钮、答对/答错反馈这些「关键时刻」保持高饱和与手感； 其余界面全部安静下来（发丝线分层、无纹理画布、语义色退到浅底色），让用户长时间答题不视觉疲惫。 v1.2 再做两件事：移除装饰性手写字体（层级改由字重承担）、提亮按钮色板并统一线性图标 —— 视觉更年轻，情绪依然交给小智与语义色。

关键词
纸面暖底 一屏一用力 发丝线分层 按压式按钮 语义色按需出现 鼓励式文案

02色彩系统

高饱和色承载固定语义且有「出现预算」：绿与红只出现在判题反馈，黄只出现在奖励时刻，橙是唯一的高频强调色。底色体系为纸面暖白，长时间注视不刺眼。

纸面白 #FBF9F5手机屏底色，暖而不黄
活力橙 #FF7548唯一高频强调色：CTA · 选中态 · 当前进度（v1.2 提亮）
深橙（按压） #EA5A24主按钮 4px 实底阴影，模拟物理按压
正确绿 #28A461正确答案 · 继续推进 · 讲解（反馈时刻出现）
红笔红 #E63946错误订正 · 连击火焰（仅反馈时刻出现）
荧光黄 #F5B841XP 与奖励时刻（出现即代表「得分了」）
墨色 #2E2A26柔和近黑：正文与交互描边
蓝墨水 #2B6CB0链接 · 单选题 · 判断题「正确」

辅助色：画布 #F4F1EB、发丝线 #E7E2D7、微信绿 #07C160（仅登录/分享）、小智肤色 #FFE9D2。v1.2 起奖励口径收敛为单一 XP，不再使用金币。

03字体系统

v1.2 起全站移除装饰性手写字体，只保留一套系统无衬线字族（PingFang SC / 微软雅黑），层级用「字重 × 字号」建立：大字时刻用 700-800 重字重压场，正文 400-500 保持安静 —— 情绪交给小智与色彩，字本身不再抢戏。

RAG（检索增强生成）= 先从知识库里「翻书」找资料，再让大模型「照着答案」组织语言。它让 AI 回答有据可依，减少一本正经地胡说八道。

鼓励式文案原则

「差一点！正确答案是 B」代替「回答错误」；「知道了，继续」代替「下一题」。

全站单一无衬线字族，层级靠字重而非换字体；800 重字重只出现在 ≥20px 大字上，一屏至多一处。

04按钮 · 按压感只留给实底主按钮

实底按钮保留 4px 按压实底阴影（触觉反馈是功能，不是装饰）；次级按钮改为发丝线描边 + 极淡投影，视觉重量让位给主操作。下方按钮均可点击体验。v1.2 色板更新：橙提亮为 #FF7548、绿换为活力绿 #28A461（按压阴影同色系加深），按钮文字改用 700 字重系统字。

主操作（CTA）
橙 = 提交 / 开始 / 生成；绿 = 答对后的继续推进（正向联想）。
次级与柔和操作
答错后的主按钮用浅橙底降低惩罚感（「安全的失败」）。
禁用与危险
危险操作仅在退出闯关确认弹层出现；微信绿仅用于登录与分享。

09视觉细节规范

元素规范
描边分级静态内容用发丝线 1px #E7E2D7 或无描边；交互元素（选项 / 幽灵按钮）1.5px；反馈讲解卡允许 2px 语义描边；主按钮无描边靠实底色。全局禁止「满屏同粗描边」。
圆角统一体系：卡片 16px / 按钮 14px / 胶囊 999px / 手机 36px；仅作业本输入卡保留微抖动圆角作为手绘签名。
阴影柔和投影仅两处：手机外框与反馈抽屉 0 6px 18px rgba(62,52,40,.06)；按压实底阴影仅留给实底主按钮（功能触觉，非装饰）；卡片间不叠投影。
画布与纸面画布纯色 #F4F1EB 零纹理；手机屏纸面 #FBF9F5；白色卡片承载内容。作业本横格线 + 红装订线全站仅输入卡一处。
语义色预算绿 / 红只出现在判题反馈与订正时刻；黄只出现在 XP 与奖励时刻；橙是唯一高频色。一屏之内高饱和色块 ≤ 1 处重点 + 反馈时刻。
字体单一系统无衬线字族（PingFang SC / Microsoft YaHei），层级靠字重（400 / 500 / 700 / 800）与字号建立；800 重字重仅用于 ≥20px 大字，一屏至多一处。不引入装饰性手写字体。
图标预算导航与系统图标一律用单色线性 SVG（stroke 2px，选中橙 / 未选灰），禁止 emoji 做导航图标；emoji 仅保留：奖励（⭐）、连击（🔥）、反馈卡头（📖✏️）、状态标记（✓✗）。
动效原则动效只回答用户动作：反馈抽屉 slide-up、奖励 chip pop 级联、答错选项轻摇 3px；吉祥物待机漂浮为唯一环境动效。无刺眼闪烁、无自动轮播。
失败安全答错不弹刺眼红屏；正确项同步标绿；按钮文案「知道了，继续」；进度条照常前进（借鉴多邻国「答错也有推进感」）。
文案语气鼓励式、口语化、带校园梗：「小智正在拼命出题…」「差一点！」「把知识做成关卡，记忆会更深。」；禁止「错误 / 失败 / 惩罚」作为大标题。
无障碍交互元素提供 :focus-visible 焦点环（2px 橙色外描边）；尊重 prefers-reduced-motion 关闭全部动效；正文对比度 ≥ 4.5:1。
