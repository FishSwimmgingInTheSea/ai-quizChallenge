# Spec Delta

## Purpose

让用户上传私有文档（pdf / docx / md / txt）建立个人知识库：后端解析、中文优先分块、向量化并写入按用户隔离的向量库，提供文档列表 / 详情 / 删除管理，处理为后台异步任务（状态机 `processing → ready / failed`），并面向出题提供仅限本人、仅限选中文档的语义检索，使公网搜不到的私有资料也能成为出题依据。

## ADDED Requirements

### Requirement: 知识库文档上传与受理

系统 SHALL 允许已登录用户上传 pdf / docx / md / txt 文档建立私有知识库，并在受理阶段完成格式、大小与非空校验；受理成功 MUST 立即返回文档标识与初始处理状态 `processing`，实际解析与向量化 MUST 由后台异步任务完成，不阻塞上传响应。未登录用户 MUST NOT 上传文档。

#### Scenario: 上传合法文档受理成功

- **WHEN** 已登录用户上传一个格式受支持、内容非空且未超过大小上限的文档
- **THEN** 系统落库一条 `processing` 状态的文档记录、保存原始文件，并立即返回文档标识与 `processing` 状态，随后由后台任务解析向量化

#### Scenario: 拒绝不支持的格式

- **WHEN** 用户上传的文档扩展名不属于 pdf / docx / md / txt
- **THEN** 系统拒绝受理并返回输入校验错误，不创建文档记录

#### Scenario: 拒绝空文件或超大文件

- **WHEN** 用户上传的文档内容为空，或大小超过配置上限
- **THEN** 系统拒绝受理并返回输入校验错误，不创建文档记录

#### Scenario: 未登录不得上传

- **WHEN** 未携带有效登录凭证的请求尝试上传文档
- **THEN** 系统返回未登录错误，不受理任何文档

#### Scenario: 知识库未开放或未配置向量模型

- **WHEN** 知识库总开关关闭，或运行环境未配置向量模型密钥
- **THEN** 系统拒绝受理上传并返回可读的不可用提示，不创建文档记录

### Requirement: 文档后台解析与向量入库

系统 SHALL 在后台任务中把受理的文档解析为纯文本、按中文优先规则分块、经向量模型嵌入后写入向量库，并以状态机记录结果：成功置 `ready` 并记录字符数与分块数，失败置 `failed` 并记录截断后的错误原因。后台任务 MUST NOT 因任何异常向上抛出而使任务丢失；文档解析不出有效文本（如扫描件 / 图片型）MUST 归为失败并给出可读原因。

#### Scenario: 解析向量化成功

- **WHEN** 后台任务成功解析并分块一个受理的文档、且向量写入完成
- **THEN** 该文档状态更新为 `ready`，并记录解析得到的字符数与分块数，此后可被检索出题

#### Scenario: 解析或向量化失败

- **WHEN** 后台任务在解析、分块或向量化过程中发生任何异常（含文档无有效文本、向量服务不可用）
- **THEN** 该文档状态更新为 `failed` 并记录截断后的错误原因，后台任务不向上抛异常，其他文档与请求不受影响

#### Scenario: 仅处理待处理文档

- **WHEN** 后台任务被调度执行，但目标文档不存在、不属于该用户，或状态已不是 `processing`
- **THEN** 系统跳过处理，不重复写入向量、不改变已终态文档的状态

### Requirement: 每用户知识库隔离

系统 MUST 保证知识库在用户之间物理隔离：每个用户的文档向量存放在其专属集合中，任何检索、取样与删除 MUST 仅作用于当前用户自己的数据。跨用户访问他人文档 MUST NOT 返回任何内容。

#### Scenario: 检索仅命中本人数据

- **WHEN** 某用户发起知识库检索
- **THEN** 检索范围被限定在该用户专属集合内，绝不返回其他用户的文档内容

#### Scenario: 文档级隔离

- **WHEN** 检索限定了具体文档集合
- **THEN** 系统仅在该文档集合内返回片段，同用户的其他未选文档不参与本次召回

### Requirement: 知识库文档管理

系统 SHALL 为已登录用户提供其知识库文档的列表、详情与删除能力；列表 MUST 按创建时间倒序并支持分页，且 MUST 只包含当前用户自己的文档。删除 MUST 一并清理向量数据、原始文件与文档记录，并 MUST 幂等（重复删除或对象已不存在不报错）。用户 MUST NOT 读取或删除他人文档。

#### Scenario: 查看本人文档列表

- **WHEN** 已登录用户请求知识库文档列表
- **THEN** 系统返回该用户自己的文档（含状态、文件名、类型、大小、分块数、创建时间等），按创建时间倒序并支持分页

#### Scenario: 删除文档清理三处数据

- **WHEN** 已登录用户删除一个属于自己的文档
- **THEN** 系统清理该文档的向量数据、原始文件与文档记录，后续列表与检索不再包含该文档

#### Scenario: 不得访问他人文档

- **WHEN** 用户请求详情或删除一个不属于自己的文档标识
- **THEN** 系统按文档不存在处理并返回相应错误，不泄露该文档的任何信息

### Requirement: 知识库检索供出题引用

系统 SHALL 面向出题提供知识库语义检索：检索 MUST 在构建时锁定发起用户与选中文档集合，调用方只能控制检索词与返回条数（条数 MUST 有上限）；检索 MUST 返回带来源文件名标识的原文片段。检索过程中的一切异常 MUST 降级为空结果或不可用提示，MUST NOT 使出题任务失败。

#### Scenario: 按检索词返回本人选中文档片段

- **WHEN** 出题研究阶段以某检索词请求知识库检索
- **THEN** 系统在锁定的用户与选中文档范围内返回语义最相关的原文片段，并标注每段的来源文件名

#### Scenario: 检索条数受上限约束

- **WHEN** 调用方请求的返回条数超过配置上限
- **THEN** 系统拒绝超出上限的取值，返回条数始终不超过配置的最大值

#### Scenario: 检索异常降级不影响出题

- **WHEN** 知识库检索因向量服务波动或其他原因发生异常
- **THEN** 系统返回空结果或不可用提示而非抛出异常，出题链路据此改用其他资料来源或继续，任务不因此失败
