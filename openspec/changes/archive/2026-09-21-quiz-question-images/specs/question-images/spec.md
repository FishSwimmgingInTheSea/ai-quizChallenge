# Spec Delta

## Purpose

为 AI 生成的题目按内容自动配上相关图片（如英语单词配实物图、历史/地理/动植物配相关图），提升学习记忆效果：出题时可选开启，系统据题目内容构建生图提示词，用阿里云百炼文生图模型生成图片、下载后转存腾讯云 COS 换取永久 URL 回填题目，并对每人每日生图数量加以限额；任何不可用或失败情形均静默降级为「题目正常返回、只是不带图」，绝不影响出题主流程。

## ADDED Requirements

### Requirement: 按题目内容构建生图提示词

系统 SHALL 根据题目的题干（并可选结合知识点、题型、正确选项）自动构建文生图提示词，使图片与题目内容语义相关。提示词 MUST 为纯函数式产出、不依赖外部服务，且 MUST 附带固定的画面风格约束（如简洁、无文字水印、适合学习场景）。提示词长度 MUST 有上限以避免超长。

#### Scenario: 依据题干生成相关提示词

- **WHEN** 系统为一道题构建生图提示词
- **THEN** 提示词围绕该题题干与核心知识点描述目标画面，并附带统一风格约束，使生成的图片与题目内容相关

#### Scenario: 提示词超长被截断

- **WHEN** 题目题干过长导致拼接出的提示词超过配置上限
- **THEN** 系统将提示词截断到上限以内，仍产出可用的生图提示词

### Requirement: 文生图并转存永久存储

开启配图时，系统 SHALL 调用文生图模型按提示词生成一张图片，取得临时图片地址后 MUST 下载图片字节并上传至对象存储，换取永久可访问的 URL 作为题目配图。生图与上传 MUST 有超时保护。系统 MUST NOT 直接把文生图返回的临时地址作为最终配图 URL 存入题目。

#### Scenario: 生图并转存成功回填永久 URL

- **WHEN** 一道题的文生图与对象存储上传均成功
- **THEN** 该题的配图字段被回填为对象存储的永久可访问 URL，前端可直接展示

#### Scenario: 生图或上传失败该题不带图

- **WHEN** 某道题的文生图调用、图片下载或对象存储上传发生异常或超时
- **THEN** 系统放弃该题配图（配图字段为空），题目其余内容与整体出题任务照常完成，不因该题失败而中断

### Requirement: 配图能力仅限登录用户

配图能力 MUST 仅对已登录用户开放。匿名请求即使勾选了配图开关，系统 MUST 静默降级为不配图，并 MUST 给出「登录后才能生成配图」的友好提示，而不是报错或阻塞出题。

#### Scenario: 匿名用户勾选配图被降级并提示

- **WHEN** 未登录用户提交的出题请求勾选了配图开关
- **THEN** 系统正常出题但所有题目均不带配图，并返回一条提示说明配图需登录后使用

#### Scenario: 登录用户勾选配图正常生效

- **WHEN** 已登录用户提交的出题请求勾选了配图开关且配额充足、依赖可用
- **THEN** 系统为题目生成配图并回填永久 URL

### Requirement: 每人每日生图限额

系统 SHALL 对每个用户每天可生成的配图数量设置上限（可通过配置调整，默认 20 张）。用量 MUST 按用户按自然日持久化计数，且计数递增 MUST 原子安全以应对同用户并发出题。达到当日上限时，系统 MUST 停止为该用户继续生图并降级为不配图，同时给出「今日配图额度已用完」的友好提示；配额 MUST 在跨自然日后自动恢复。

#### Scenario: 配额内正常计数

- **WHEN** 已登录用户当日累计生图数量未达上限时生成配图
- **THEN** 系统成功生图并将该用户当日用量计数递增

#### Scenario: 达到当日上限降级

- **WHEN** 已登录用户当日累计生图数量达到配置上限后再次请求配图
- **THEN** 系统不再为其生图，题目正常返回但不带配图，并给出今日额度已用完的友好提示

#### Scenario: 跨自然日配额恢复

- **WHEN** 用户在用尽当日额度后于次日再次请求配图
- **THEN** 系统按新的自然日重新计数，用户可再次在上限内生成配图

#### Scenario: 并发出题计数不超发

- **WHEN** 同一用户并发发起多个出题任务且剩余额度有限
- **THEN** 系统通过原子计数保证实际生图总数不超过当日上限，不出现超发

### Requirement: 配图不可用时静默降级

当配图依赖不可用时——包括未配置文生图密钥、未配置对象存储凭据、或配图总开关关闭——系统 MUST 静默降级为不配图完成任务，而不是让出题失败，并 MUST 记录降级事件。降级 MUST NOT 改变题目其余字段与出题链路的既有行为。

#### Scenario: 未配置密钥或存储凭据

- **WHEN** 用户勾选配图但运行环境未配置文生图密钥或对象存储凭据
- **THEN** 系统正常出题、所有题目不带配图，任务不失败，日志记录降级原因

#### Scenario: 配图总开关关闭

- **WHEN** 配图总开关关闭时用户勾选配图出题
- **THEN** 系统忽略配图请求，按无配图路径完成出题，任务不因此失败

### Requirement: 配图 URL 随题目结构与历史记录持久化

题目对外数据结构 SHALL 新增一个可选的配图 URL 字段，默认取值为空以保证向后兼容；该字段 MUST NOT 改变题目其余字段的名称、语义与取值约束。题目结算落库的题目快照 MUST 保存配图 URL，历史记录详情回读时 MUST 一并返回，使历史回看与实时答题都能展示当时的配图。

#### Scenario: 未配图时结构向后兼容

- **WHEN** 出题未开启配图或某题未成功配图
- **THEN** 该题配图字段为空串，题目结构与既有前端完全兼容，无需修改即可渲染

#### Scenario: 历史记录保留配图

- **WHEN** 一局带配图的题目完成结算落库后，用户查看该历史记录详情
- **THEN** 详情返回的每道题都带有当时保存的配图 URL，回顾界面可展示配图
